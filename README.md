# AI.HERE BADᴍᴛ-Zone (v3 — Web Edition: HTML/CSS/JS + FastAPI + SQLite)

เว็บแอปพลิเคชันร้านขายอุปกรณ์แบดมินตันครบวงจร ย้ายชั้น UI จาก CustomTkinter เดิมมาเป็น **HTML + CSS + JavaScript (ES Modules, ไม่ต้องใช้ npm/build step)** โดยมี **Python (FastAPI + Uvicorn) + SQLite** เป็นหลังบ้าน ทำงานร่วมกันเป็นระบบเดียว (`python main.py` แล้วเปิดเบราว์เซอร์ใช้งานได้ทันที)

คงรูปลักษณ์และฟีเจอร์เดิมครบทุกประการ: ธีมสีเหลือง (`#FFB703` / `#FFD600`) · แดง (`#E63946`) · ขาว/ดำ (`#FFFFFF` / `#141619`), ฟอนต์ไทย `Kanit` + อังกฤษ/ตัวเลข `Arimo`, รองรับโหมดสว่าง/มืด (Light / Dark Mode) และครบทั้ง **30 หน้าจอ** (`18 หน้าผู้ซื้อ + 12 หน้าแอดมิน/เจ้าของร้าน`)

## 1. การติดตั้ง (รองรับ Python 3.10 – 3.15)

> **ใช้ `python` หรือ `py`?** ขึ้นอยู่กับเครื่อง — Windows ที่ติดตั้ง Python จาก python.org มักใช้ `py` ได้เสมอ ส่วน macOS / Linux ส่วนใหญ่ใช้ `python3` หรือ `python`
> - **หลังเปิดใช้งาน `.venv` แล้ว ใช้ `python` ได้ทุกเครื่อง** (ไม่ต้องสนใจว่าเครื่องตัวเองใช้ `py` หรือไม่)
> - เอกสารนี้เขียนคำสั่งเป็น `python ...` ถ้ายังไม่ได้เปิด `.venv` และเครื่องของคุณใช้ `py` ให้เปลี่ยนเป็น `py ...`

### ขั้นที่ 1: สร้างและเปิดใช้งาน Virtual Environment (`.venv`)

**กรณีเครื่องใช้ `py` (Windows):**
```bash
py -m venv .venv
.venv\Scripts\activate
```

**กรณีเครื่องใช้ `python` (Windows / macOS / Linux):**
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate        # macOS / Linux
```
(macOS / Linux บางเครื่องต้องพิมพ์ `python3 -m venv .venv`)

เมื่อเปิดใช้งานสำเร็จ หน้าบรรทัดคำสั่งจะมี `(.venv)` นำหน้า
> ถ้า PowerShell ขึ้น error ว่าสั่ง activate ไม่ได้ ให้รัน `Set-ExecutionPolicy -Scope Process Bypass` ก่อน แล้ว activate อีกครั้ง

### ขั้นที่ 2: ติดตั้งไลบรารีทั้งหมด
```bash
pip install -r requirements.txt
```

### ขั้นที่ 3: สร้างไฟล์ตั้งค่า `.env`
```bash
copy .env.example .env      # Windows (Command Prompt)
cp .env.example .env        # macOS / Linux / Git Bash
```
จากนั้นเปิด `.env` แล้วกรอกค่าตามหัวข้อ 3 (ไฟล์ `.env` ห้ามนำขึ้น Git)

## 2. การรันโปรแกรมและตรวจสอบระบบ

รันคำสั่งจากโฟลเดอร์รากของโปรเจกต์ (โฟลเดอร์ที่มี `main.py`) โดยเปิด `.venv` ไว้ก่อน:

```bash
python main.py          # เริ่มเซิร์ฟเวอร์ FastAPI/Uvicorn บน http://127.0.0.1:8000 และเปิดเบราว์เซอร์อัตโนมัติ
python main.py --check  # ตรวจความพร้อมก่อนรัน (ไลบรารี, ฐานข้อมูล, หน้าเว็บทั้ง 30 หน้า, API endpoints, PromptPay QR, ฟอนต์ Kanit/Arimo, AI, OTP_SECRET และ SMTP)
```
ถ้าไม่ได้เปิด `.venv` และเครื่องใช้ `py` ให้พิมพ์ `py main.py` และ `py main.py --check` แทน

ตัวเลือกเพิ่มเติมตอนรัน `main.py`:
- `python main.py --host 127.0.0.1 --port 8000` — กำหนด host/port เอง
- `python main.py --no-browser` — รันเฉพาะเซิร์ฟเวอร์โดยไม่ต้องเปิดเบราว์เซอร์อัตโนมัติ

ครั้งแรกระบบสร้างฐานข้อมูล `data/shop.db` พร้อมสินค้าและบัญชีตัวอย่างให้เอง (ดูหัวข้อ 4)

## 3. การตั้งค่าระบบส่งอีเมลจริง (SMTP) และรหัสยืนยัน OTP ผ่านไฟล์ `.env`

ระบบ OTP ยืนยันทางอีเมลของโปรเจกต์ทำงานผ่านการส่งอีเมลจริงด้วย SMTP เท่านั้น (ไม่มีโหมดแสดงรหัสทดสอบบนหน้าจอหรือใน API response) โดยเข้ารหัสรหัส OTP ในฐานข้อมูลด้วย **HMAC-SHA256** (`OTP_SECRET`)

### 3.1 ขั้นตอนการสร้าง Gmail App Password (รหัสผ่านแอป 16 ตัวอักษร)

การใช้ Gmail ส่งอีเมลออกจากระบบต้องใช้ **App Password (รหัสผ่านสำหรับแอป)** แทนรหัสผ่านเข้าอีเมลปกติ โดยมีขั้นตอนดังนี้:

1. เข้าสู่บัญชี Google ของอีเมลร้านที่ [https://myaccount.google.com/](https://myaccount.google.com/)
2. ไปที่เมนู **Security (ความปลอดภัย)** ทางด้านซ้าย
3. ในหัวข้อ "How you sign in to Google" ให้เปิดใช้งาน **2-Step Verification (การยืนยันแบบ 2 ขั้นตอน)** ให้เรียบร้อยก่อน (จำเป็นต้องเปิดก่อนจึงจะสร้าง App Password ได้)
4. พิมพ์ค้นหาคำว่า **App passwords (รหัสผ่านสำหรับแอป)** ในช่องค้นหาด้านบนของหน้าบัญชี Google หรือเข้าไปในส่วนตั้งค่าของ 2-Step Verification แล้วเลื่อนลงล่างสุด
5. ตั้งชื่อแอปตามต้องการ เช่น `AI.HERE BADᴍᴛ-Zone` แล้วกดปุ่ม **Create (สร้าง)**
6. ระบบจะแสดงรหัสผ่าน 16 ตัวอักษร (อยู่ในกรอบสีเหลือง) ให้คัดลอกรหัสทั้ง 16 ตัวอักษรนั้น (ตัดช่องว่างออกให้ติดกันเป็น 16 ตัวอักษร) มาใส่ในตัวแปร `SMTP_PASSWORD` ในไฟล์ `.env`

### 3.2 ขั้นตอนการสร้างค่าลับ `OTP_SECRET` และการตั้งค่าไฟล์ `.env`

1. ใช้ไฟล์ `.env` ที่คัดลอกจาก `.env.example` ในขั้นที่ 3 ของหัวข้อ 1 (ไฟล์ `.env` ถูกกันไว้ใน `.gitignore` แล้ว ห้ามนำขึ้น Git เด็ดขาด)
2. สร้างค่าลับสุ่มสำหรับ `OTP_SECRET` (ความยาวอย่างน้อย 32 ตัวอักษร) ด้วยคำสั่ง (เครื่องที่ใช้ `py` ให้พิมพ์ `py -c ...`):
   ```bash
   python -c "import secrets; print(secrets.token_urlsafe(48))"
   ```
3. นำค่าที่ได้ไปใส่ใน `.env` และเลือกโหมดการทำงานของเซิร์ฟเวอร์ตามสภาพแวดล้อม:

#### โหมด A: ทดสอบในเครื่อง (Local Development)
ใช้เมื่อรันทดสอบบนคอมพิวเตอร์เครื่องเดียวผ่าน `http://127.0.0.1:8000` (ยังไม่มี HTTPS):

```env
HOST=127.0.0.1
PORT=8000
COOKIE_SECURE=0
SESSION_COOKIE_NAME=badminton_session

OTP_SECRET=ใส่ค่าลับสุ่มที่สร้างจากคำสั่งด้านบน_ความยาวอย่างน้อย_32_ตัวอักษร

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_shop_email@gmail.com
SMTP_PASSWORD=abcdefghijklmnop
SMTP_FROM_NAME=AI.HERE BADᴍᴛ-Zone
SMTP_FROM=
```

#### โหมด B: ขึ้นเซิร์ฟเวอร์จริงที่มี HTTPS (Production Server)
ใช้เมื่อนำระบบขึ้นเซิร์ฟเวอร์จริงที่อยู่หลัง Reverse Proxy (เช่น Nginx / Cloudflare) และเปิดใช้งาน HTTPS แล้ว:

```env
HOST=0.0.0.0
PORT=8000
COOKIE_SECURE=1
SESSION_COOKIE_NAME=badminton_session

OTP_SECRET=ใส่ค่าลับสุ่มที่สร้างจากคำสั่งด้านบน_ความยาวอย่างน้อย_32_ตัวอักษร

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_shop_email@gmail.com
SMTP_PASSWORD=abcdefghijklmnop
SMTP_FROM_NAME=AI.HERE BADᴍᴛ-Zone
SMTP_FROM=
```

- **พอร์ต SMTP ที่รองรับ:** รองรับทั้ง `SMTP_PORT=587` (STARTTLS — แนะนำ) และ `SMTP_PORT=465` (SSL/TLS)
- **ความเข้ากันได้ย้อนหลัง:** รองรับทั้งตัวแปร `SMTP_PASSWORD` และชื่อเดิม `SMTP_PASS` และหากเว้น `SMTP_FROM` ว่างไว้ ระบบจะใช้ค่าจาก `SMTP_USER` ร่วมกับ `SMTP_FROM_NAME` ให้อัตโนมัติ

> **ข้อควรระวังด้านความปลอดภัยเมื่อเปิดให้เครื่องอื่นเข้าถึง (`HOST=0.0.0.0`):**
> ระบบจะปฏิเสธการเริ่มเซิร์ฟเวอร์บนเครือข่ายภายนอกหากบัญชี `owner`, `admin1` หรือ `buyer1` ยังใช้รหัสผ่านตัวอย่างตั้งต้นอยู่ กรุณาเปลี่ยนรหัสผ่านของบัญชีตัวอย่างทั้งหมดก่อนเปิดให้เครื่องอื่นเข้าใช้งาน

### 3.3 วิธีทดสอบการส่งและยืนยัน OTP จริงด้วยตัวเองครบทั้ง 3 จุด

หลังจากตั้งค่า `.env` และรัน `python main.py` แล้ว สามารถทดสอบการทำงานของอีเมล OTP ทั้ง 3 จุดได้ดังนี้:

1. **จุดที่ 1 — สมัครสมาชิกใหม่ (`purpose = register`):**
   - ไปที่หน้าเข้าสู่ระบบ แล้วกดปุ่มสลับไปหน้า **SIGN UP (สมัครสมาชิกใหม่)**
   - กรอกชื่อผู้ใช้, อีเมลจริงของคุณ, ชื่อ-นามสกุล, รหัสผ่าน และกดปุ่ม **"ส่งรหัส OTP ไปที่อีเมล"**
   - หน้าเว็บจะแสดงข้อความ `"ส่งรหัสไปที่ xx***@domain แล้ว"` พร้อมปุ่มนับถอยหลัง 60 วินาที
   - เปิดกล่องจดหมายอีเมลของคุณ จะได้รับอีเมลรูปแบบ HTML ธีมสีเหลือง-ดำ-ขาว สองภาษา (ไทย/อังกฤษ) นำรหัส 6 หลักมากรอกและกด **"ยืนยันรหัส OTP และสร้างบัญชีสมาชิก"**
2. **จุดที่ 2 — ลืมรหัสผ่าน (`purpose = reset`):**
   - ในหน้า **LOGIN (เข้าสู่ระบบ)** กดปุ่ม **"ลืมรหัสผ่าน? (รับรหัส OTP)"**
   - กรอกอีเมลบัญชีผู้ซื้อที่สมัครไว้ แล้วกด **"ส่ง OTP"** (ปุ่มจะนับถอยหลัง 60 วินาทีก่อนขอซ้ำได้)
   - นำรหัส OTP 6 หลักจากอีเมลมากรอก พร้อมตั้งรหัสผ่านใหม่ (อย่างน้อย 8 ตัวอักษร) แล้วกด **"ยืนยันเปลี่ยนรหัสผ่าน"**
   - ทดลองเข้าสู่ระบบด้วยรหัสผ่านใหม่ (เซสชันเดิมที่เคยล็อกอินค้างไว้ในเครื่องอื่นจะถูกยกเลิกอัตโนมัติ)
3. **จุดที่ 3 — เปลี่ยนอีเมลในหน้าโปรไฟล์ (`request-otp` / `confirm-otp`):**
   - เข้าสู่ระบบด้วยบัญชีผู้ซื้อ แล้วไปที่เมนู **"โปรไฟล์ของฉัน"**
   - กดปุ่ม **"แก้ไขข้อมูลของฉัน"** มุมขวาบนเพื่อปลดล็อกช่องกรอกข้อมูล
   - แก้ไขช่องอีเมลเป็นอีเมลใหม่ที่ต้องการเปลี่ยน แล้วกดปุ่ม **"ส่ง OTP ยืนยันอีเมลใหม่"**
   - เปิดดูอีเมลฉบับใหม่ที่ส่งไปยังอีเมลใหม่ นำรหัส OTP 6 หลักมากรอกในช่องรหัส OTP แล้วกด **"บันทึกโปรไฟล์"** และกรอกรหัสผ่านปัจจุบันเพื่อยืนยันการเปลี่ยนอีเมล

## 4. บัญชีผู้ใช้เริ่มต้นและการจัดการรหัสผ่าน

| บทบาท | อีเมล / ชื่อผู้ใช้ | รหัสผ่านเริ่มต้น | สิทธิ์การใช้งานหลัก |
|---|---|---|---|
| **Owner (เจ้าของร้าน)** | `owner@shop.com` (`owner`) | `owner123` | จัดการทุกส่วนของระบบ, รายได้/รายจ่าย, ส่งออก `.xlsx`, กฎคูปอง, ลบ/กู้คืนสินค้า-หมวด-แบรนด์, แต่งตั้งแอดมินด้วยอีเมล, แบนเนอร์, Audit Log, สำรองข้อมูล |
| **Admin (แอดมิน)** | `admin@shop.com` (`admin1`) | `admin123` | จัดการสต็อก/ข้อมูลสินค้าพื้นฐาน, ตรวจสลิปโอนเงิน, อัปเดตเลขพัสดุ, ตอบแชทลูกค้า, ดูข้อมูลติดต่อเจ้าของร้านและส่งอีเมลด่วนหาเจ้าของร้าน |
| **Buyer (ผู้ซื้อ)** | `buyer@shop.com` (`buyer1`) | `buyer123` | เลือกซื้อสินค้า, รับคูปอง, เปรียบเทียบไม้ 2–5 รุ่น, สั่งซื้อ/ชำระเงิน PromptPay QR, ติดตามออเดอร์ 8 แท็บสถานะ, รีวิวสินค้า, แชทกับร้าน/AI |

> **สำหรับโปรเจกต์ส่งงาน/ทดสอบในเครื่อง** ใช้บัญชีด้านบนล็อกอินได้เลย แต่ถ้านำไป deploy หรือเปิดให้เครื่องอื่นเข้าถึง ให้ตั้ง `OWNER_INITIAL_PASSWORD` ใน `.env` หรือเปลี่ยนรหัสผ่านก่อนเสมอ

### การรีเซ็ตรหัสผ่านพนักงาน/เจ้าของร้านผ่าน CLI (`tools/reset_password.py`)
```bash
python tools/reset_password.py --email admin@shop.com --password รหัสผ่านใหม่123
```
(เครื่องที่ใช้ `py` โดยไม่เปิด `.venv` ให้พิมพ์ `py tools/reset_password.py ...`)

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```
(เครื่องที่ใช้ `py` โดยไม่เปิด `.venv` ให้พิมพ์ `py -m unittest ...`)
